Clean Architecture Layers

💎 Domain Entities, Value Objects, Business Rules
🔧 Infrastructure Database, External Services

The Dependency Rule: Outer layers depend on inner layers, never the reverse.

Key Features

What makes Vision 2026 different

📦 Value Objects

Self-validating, immutable data types. Validation happens once at creation, then the object is always valid.

🎯 Domain Events

Record what happened for loose coupling. Notifications, indexing, and analytics all decoupled.

🧪 Testable Design

Domain layer tests run in milliseconds with zero external dependencies. No database needed.

🔄 Repository Pattern

Interface in Domain, implementation in Infrastructure. Swap databases without changing business logic.

🚀 Quick Start

  1. Download the module or clone from GitHub
  2. Set 'enabled' => true in config/demo.php for demo mode
  3. Explore src/Domain/ to see Clean Architecture in action
  4. Run composer test to see tests execute without XOOPS
